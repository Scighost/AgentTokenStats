# Agent Token Stats

Agent Token Stats 是一个基于本地会话历史记录的 Token 统计与分析工具，面向使用 AI Agent 的开发者，帮助他们直观了解自己的会话数据：一共消耗了多少 token、用在了哪些模型、项目、日期上。

核心价值：开发者每天使用不同的 AI Agent，在本地留下大量会话数据，但缺乏一个统一、直观的视角去审视这些数据的规模与成本。本产品把这些零散存储的数据变成可量化的指标。

## 使用

下载对应操作系统和 CPU 架构的二进制文件并运行，会自动打开页面。找不到数据时，在首页为对应数据源指定会话目录即可。
